# Website contribution rules

Static Astro and TypeScript marketing site. Use existing components and CSS tokens.

- Preserve approved copy, testimonial wording and attribution, and fictional-data labels.
- Do not add unsupported performance claims or identify clients.
- Do not commit credentials, client records, internal evidence, or private handoff material.
- Keep fonts self-hosted and avoid runtime third-party requests except the configured inquiry form submission.
- Maintain keyboard access, visible focus, accessible forms, and responsive behavior.
- Run the build, type checks, HTML validation, internal link checks, and relevant Playwright tests before publishing changes.
- Check affected layouts at phone, tablet, and desktop widths when changing presentation.
